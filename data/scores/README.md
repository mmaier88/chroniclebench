# Instrument score files — system entries

Full pinned-instrument output for every scored window of the two `Chronicle ×`
system entries: 5 positional windows + 1 whole-book diagnostic × 6 books × 2
entries = 72 files. Schema, provenance, and the two disclosed normalizations
(internal paths/labels dropped; Prose Authenticity fingerprint summarized rather
than listed per pattern) are documented in [`../README.md`](../README.md).

File naming: `obr-<entry>-<brief>-<replicate>[--<window>].json`; no `--<window>`
suffix = the whole-book diagnostic pass (never used for ranking).
